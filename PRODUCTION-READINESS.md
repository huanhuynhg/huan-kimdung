# Wedding V2.16 – Production Cleanup

## Changes in this build
- Removed Local QA panel, local-only date overrides, demo RSVP, demo guestbook data, and QA-only behavior from the runtime JavaScript.
- Memories mode is selected from the configured Lễ Thành Hôn date: it activates at 00:00 on the following calendar day in `Asia/Ho_Chi_Minh`.
- After Memories mode activates, event details, the original gallery, RSVP, guestbook, and contact section are hidden; the Memories gallery is shown.
- Memories photo manifest is loaded at runtime and generated by the GitHub Pages workflow from `assets/memories/photos/`.
- Memories pagination remains separate from “Khoảnh khắc của chúng mình”, with at most 15 photos per page and dots only when more than one page exists.
- Contact cards now link directly to the Facebook profiles sourced from V1.

## Before publishing
1. Copy all intended memory photos into `assets/memories/photos/` (JPG/JPEG/PNG/WebP/AVIF/GIF).
2. Confirm `wedding.config.json` event dates, venues, and the `site.url` match the target repository URL.
3. If enabling Guestbook, set `guestbook.enabled=true` and configure/test the separately deployed Apps Script endpoint. It is disabled by default in this build.
4. Keep repository root layout: `index.html`, `css/`, `js/`, `assets/`, `scripts/`, `wedding.config.json`, and `.github/workflows/pages.yml` must be at the repository root, not nested inside another folder.
5. In GitHub repository settings, set Pages source to GitHub Actions. The workflow currently deploys on pushes to branch `main` and supports manual dispatch.
6. Review the GitHub Actions build/deploy result before sharing the URL.
